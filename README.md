# 🎮 Number Guessing Game

## 📌 Project Description
This is a simple Java console-based game where the user has to guess a randomly generated number between 1 and 100.  
The program gives hints if the guessed number is too high or too low until the correct number is found.

---

## 🚀 Features
- Random number generation (1 to 100)
- User input handling
- Feedback system (Too High / Too Low)
- Limited number of attempts
- Score tracking
- Option to play multiple rounds
- Input validation (handles invalid inputs)

## 🛠 Technologies Used
- Java
- Random class
- Scanner class
- Loops (while)
- Conditional statements (if/else)
- Exception handling (try/catch)

---

## 📊 Game Rules
- You have limited attempts to guess the number
- Each wrong guess reduces attempts
- Game ends when:
  - You guess correctly 
  - Attempts reach zero
